# 技法规范（基于 Astraumbra《各大主流AI大模型拟人形象整理》13 张原图核对）

## 一、画风 & 线条（最核心，保证画风统一）

1. **线稿**：干净清晰的黑色轮廓线，粗细有变化——外轮廓略粗、内部装饰细线；**没有杂乱排线**；日系平涂 + 薄渐变（软阴影），不是厚涂。
2. **上色质感**：低对比度、柔和赛璐璐，少量珠光/清透质感；高光小而精致，拒绝大面积刺眼高光；色彩饱和度适中，固色干净。
   - **对比度规则（重要）**：对比度跟随品牌色调性——品牌色浅（GPT 白、混元黑白、LLaMA 奶白）→ 低对比灰调/粉调梦幻；品牌色深（Grok 黑红金、Mistral 红白）→ 高对比华丽。不要一刀切用低对比。
3. **五官与头身**：日系少女脸，精致文静的二次元大眼，瞳孔带小高光；脸型偏修长；写实比例少女约 **6.5–7 头身**（腿部略拉长），不 Q 版。
4. **背景**：纯白底（#FFFFFF）为主，无环境背景。例外规则见构图版式一节。

## 二、构图与版式（系列感关键）

- **全身立绘**：完整从头到脚，人物居中，**角色占画面约 75–85%**，不裁切。
- **站姿**：放松自然的静态站姿，微微侧身，重心稳定；手做轻小动作（托书、抬手、拎裙摆、指向前方），不大幅动态。性格可视化允许例外：Grok 扶斧、MiniMax 指向镜头方向。
- **镜头**：正面微侧平视，无透视畸变，标准立绘构图。
- **背景例外规则**：默认纯白空底；仅当角色人设强烈需要时，允许**极淡的同色系单色装饰元素**（如 Kimi 的月亮、彩虹光束、飘落乐谱——全部为低饱和浅紫灰调，不抢人物主体）。

## 三、人设设计逻辑（系列灵魂：模型特性拟人）

### 核心规则：模型特点 → 视觉符号

先定符号再画图。每个角色由四层符号构成：

1. **种族/兽设**：给模型分配代表生物。
2. **主色调**：提取品牌 LOGO 色作为角色主色（发色、裙色、瞳色局部呼应）。
3. **标志性道具**：手持物直接对应模型核心能力。
4. **性格可视化**：表情、姿态贴合模型社区人设。
5. **皮肤红线（强制）**：**兽化特征一律不得作用于皮肤**。肤色必须是正常人类肤色，皮肤上不得有鳞片、兽纹、羽化、斑纹、鳞甲、半透明/异色皮肤或任何非人皮肤质感。

#### 种族特征的合法位置（只在"配件层"表达）

角 / 兽耳 / 尾巴 / 羽饰等体外附件、头饰与额饰、发色与发型（含渐变、异色发尾）、瞳色与瞳形（竖瞳、异色瞳）、服装纹样与刺绣、配饰挂件（鳞纹可用在**布料/金属/皮革材质的服饰与护腕**上，但不能是皮肤）、鞋袜与手套（属服装层，非皮肤）。

> 判定口诀：**能摘下来的特征才允许**——皮肤不能摘，所以皮肤永远保持人类正常肤色。

### 服装体系（重要修正）

服装类型**由模型人设决定，不限于洋装**：

- 默认池：复古洋装、洛丽塔、改良国风礼服、华丽长裙（大裙摆、荷叶边、褶皱丰富）。
- 合法变体：现代职业休闲（MiniMax）、病号服（Qwen）、睡衣家居（LLaMA）、冬装大衣（混元）。
- **系列统一性靠线稿、上色质感、白底和版式保证，不靠服装品类。**
- 裙身/配饰印品牌标识符号或 LOGO 字母（蝴蝶结、挂件、刺绣、钥匙扣均可承载）。
- 鞋：高跟鞋/小皮鞋/靴子/运动鞋，随服装体系变化。

### 性格可视化示例

冷静书卷气（Claude、Z.ai）、活泼元气（DeepSeek、Grok、MiniMax）、文静优雅（智谱、混元）、慵懒困倦（LLaMA）、病弱坚韧（Qwen）。

## 四、细节规范

1. **装饰**：大量精致小配饰——蝴蝶结、链条、流苏、金属宝石挂件、钥匙、徽章；纹样精细但不堆到杂乱。
2. **头发**：长发为主，飘逸大波浪，发丝分组绘制、层次丰富；发色匹配主色调（允许渐变，如紫粉、橙红）。
3. **服饰版型**：跟随服装体系；裙装则大裙摆+荷叶边+多层褶皱。
4. **特效小元素**：悬浮的小符号（星星、小云、音符、彩虹光），淡淡的、低饱和、少量，不抢人物主体。

## 六、额外创作规则

1. **先定符号再画图**：第一步提炼【代表动物 + 品牌主色 + 核心能力道具】，向用户确认后再画。
2. **固定参考图**：生成新角色时，把系列已有图作为 Image reference 传入 ImageGen 锁死画风线条；选种族/服装类型相近的参考图效果最好。技能 `assets/` 内已内置全套系列参考图（正常比例 14 张，按模型命名：GPT-白龙、Claude-古书、Grok-战斧、Kimi-三棱镜长裙、DeepSeek-鲸鱼女仆、智谱-国风礼服、Qwen-轮椅病号服、MiniMax-场记板、Mistral-法棍猫耳、混元-冬装围巾、LLaMA-羊驼睡衣、Zai-黑狐等），与上表一一对应。
3. **统一画幅**：全部竖版 9:16。
4. **合规**：属于同人二创，不冒充任何公司官方形象。

## 七、Q版（chibi）模式规范

正常比例与 Q版是同一系列的两个分支：**种族符号、配色、服装、道具、皮肤红线、白底版式全部沿用主规范，只有头身比与五官比例改变。**

1. **头身比**：2–3 头身（默认 2.5），头占全身近一半，身体圆润短小，手脚小巧。
2. **五官**：脸型圆润带婴儿肥，大眼占脸约 1/3，鼻嘴极小；**眼神与表情必须保留角色性格**（慵懒半睁、冷冽、元气均可，Q 不等于傻甜）。
3. **细节不降级**：发丝分组、服装褶皱、蕾丝纱层、纹样刺绣、链条挂坠全部精细绘制并等比缩小——Q 的是比例，不是画质。
4. **发型**：原角色的发型特征完整保留（双丸子、大波浪、发色渐变等）。
5. **动作**：小幅度可爱小动作——手放胸口、摸头发、拎裙摆、迈步走、歪头；头大结构不适合奔跑跳跃等大动态。
6. **构图**：居中、白底、无裁切；人物占画面约 60–75%（头大，占比略低于正常比例版）。
7. **皮肤红线同样适用**：Q版也必须是正常人类肤色，兽化特征只在配件层。
8. **负面清单调整**：移除 `chibi`，换入 `realistic proportions, tall body, 7 head tall, long legs, adult body proportions`；其余负面词不变。
9. **参考图**：`assets/` 内共 5 张 Q版参考——`chibi-ref-1-黑蓝舞娘`（华丽纱裙系）、`chibi-ref-2-紫黑慵懒`（外套+裙现代混搭系）、`chibi-ref-3-国风斗篷冷淡`（中式冷淡系）、`chibi-ref-4-白金制服`（制服系）、`chibi-ref-5-运动服`（休闲运动系），按服装类型就近选用。
